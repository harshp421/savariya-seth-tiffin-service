3. Select this repository: `savariya-seth-tiffin-service`.
4. Configure Build Settings:
   - **Framework preset**: `None`
   - **Build command**: *(leave empty)*
   - **Build output directory**: `/` *(or leave empty)*
5. Click **Save and Deploy**. Your site will be live instantly on a `*.pages.dev` domain with free SSL!
